# docs-site/ — publishable documentation

Generated by `npm run docs:export` from the in-app documentation (`static/admin/src/docs/content`) plus `PRIVACY.md`, `TERMS.md`, `SLA.md`. **Do not edit these files by hand** — edit the sources and re-export.

Publish options (either satisfies the "Documentation URL" + "Privacy policy URL" the Marketplace listing and install-link sharing require):

- **GitHub Pages** from a `gh-pages` branch: `git subtree push --prefix docs-site origin gh-pages`, then Settings → Pages → branch `gh-pages`, folder `/`. `index.md` is the landing page; `_config.yml` picks the minimal Jekyll theme.
- **Public Confluence space:** paste each `.md` into a page (Confluence imports Markdown), one page per file, `index.md` as the space home.

Then put the resulting URLs in the listing (Documentation, Privacy policy, EULA/Terms, Support), in the Beta app's Sharing details, and in `PRIVACY.md`/`TERMS.md`/`SLA.md` where they reference each other.
